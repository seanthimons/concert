# Pre-flight warning for CASRNs a spreadsheet converted to dates

Pre-flight warning for CASRNs a spreadsheet converted to dates

## Usage

``` r
cas_date_warning(date_coerced)
```

## Arguments

- date_coerced:

  Tibble from `precheck_normalize_cas()$date_coerced`.

## Value

A warning alert, or NULL when nothing was flagged.
