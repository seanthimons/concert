# Analyze coverage of extracted units against target dataset

Analyze coverage of extracted units against target dataset

## Usage

``` r
analyze_coverage(extracted_units, target_units, source_name)
```

## Arguments

- extracted_units:

  Character vector of extracted unit strings

- target_units:

  Character vector of target unit strings to check coverage against

- source_name:

  Name of target source for logging

## Value

List with coverage statistics
