# Apply review overrides to a replayed resolution state

Apply review overrides to a replayed resolution state

## Usage

``` r
apply_review_overrides(resolution_state, review_overrides = NULL)
```

## Arguments

- resolution_state:

  Automated resolution state from a replayed curation run.

- review_overrides:

  A function generated by
  [`generate_concert_script()`](https://seanthimons.github.io/concert/reference/generate_concert_script.md),
  a content-match spec from
  [`build_review_overrides()`](https://seanthimons.github.io/concert/reference/build_review_overrides.md),
  a legacy positional override table/list, or NULL.

## Value

Updated resolution state.
